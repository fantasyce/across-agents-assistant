# Contributor Certificate

Across Agents Assistant uses the Developer Certificate of Origin 1.1 by
reference for inbound contributions.

By contributing to this project, you certify that you have the right to submit
the contribution and that the project may distribute it under the license
indicated by the project or by the affected files.

To make that certification explicit, include a sign-off line in every commit:

```text
Signed-off-by: Your Name <your.email@example.com>
```

You can add it automatically with:

```bash
git commit -s
```

Use a real identity that you are comfortable having permanently associated with
the public contribution history. If you contribute on behalf of an employer,
organization, or client, make sure you are authorized to do so before opening a
pull request.

The canonical Developer Certificate of Origin text is maintained at:

```text
https://developercertificate.org/
```

Contributions without the required sign-off may be rejected or held until the
contributor confirms the certification.
