# Trademark Policy

This policy explains how the Across Agents Assistant project names, logos, icons, and other brand identifiers may be used.

The project code is licensed under the GNU Affero General Public License v3.0. That license covers the source code, but it does not grant permission to use project trademarks or branding in a way that suggests an unofficial build is official.

## Project Marks

The project marks include:

- Across Agents Assistant
- Across Agents Assistant logos, app icons, menu bar icons, and release artwork
- The official repository, release, and distribution names used by the maintainers

Third-party integrations and provider names, such as Claude Code, DeepSeek, MiniMax, Hermes, and compatible local CLI tools, belong to their respective owners. They are mentioned only to describe compatibility.

## Allowed Uses

You may use the project marks to:

- Refer to the original project accurately.
- Link to the official repository or documentation.
- State that your work is a fork of, compatible with, or based on Across Agents Assistant.
- Use screenshots of the unmodified official app for review, documentation, or educational purposes.

## Restricted Uses

You may not use the project marks to:

- Present a modified fork as the official Across Agents Assistant app.
- Publish a modified build with the official app name, icon, or release branding unless it is clearly labeled as unofficial.
- Register confusingly similar domain names, package names, app listings, or social accounts.
- Use the marks in a way that implies endorsement by the maintainers.

## Forks and Modified Builds

Modified builds should use a distinct name and icon. A good attribution line is:

> This project is based on Across Agents Assistant and is not an official release.

If a fork keeps visible references to Across Agents Assistant, the UI, README, release notes, and download pages must make the fork status clear.

## Permission

For uses outside this policy, ask the maintainers before publishing. Permission may be granted case by case and can be revoked if the use becomes misleading or harmful to users.
